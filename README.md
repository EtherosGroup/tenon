# Tenon

## 前言
Tenon在之前有过一个Rust开发的版本，本是看中了Rust优秀的内存管理机制，dans后面发现Rust的学习难度好像跟我手动找出所有可能的内存漏洞不相上下（而且主要是Rust这玩意太shit了，依旧Rust开发者孤立全世界），因此打算用C来重写做，之前的也就交给DeepSeek自己玩去了（）

Tenon的目标不是成为流行的操作系统，只是一群高中生闲的没事成立的一个项目，我们也欢迎大家加入和指出错误，我们共同见证一个操作系统从0->1

> 顺带一提：Tenon将采用我们设计的一个新的文件系统：[MUFS](https://github.com/EtherosGroup/mufs)，这是一次伟大的尝试（其实是夹带私货？）。

总之，好奇心不一定会害死猫，但一定能让我们在深夜盯着QEMU模拟器里那一闪而过的“Hello World”傻笑十分钟。Tenon或许永远跑不到生产环境，也干不过Linux，但它就像我们亲手焊出来的一块电路板，粗糙、简陋，甚至带着焊锡疙瘩。我们享受的，是看着那一行行C代码最终变成CPU上跳动的电信号的过程——这就是计算机最本来的浪漫。
